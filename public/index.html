Quanta Craft Launcher（QCL，量子方块启动器）是一个完全免费的 Android 版 Minecraft: Java Edition 启动器。自 1.1.1 起，启动、渲染、输入与 Java 运行时链路全部自研。 它没有广告，没有内购，也不开会员 —— 到目前为止，所有开销都由作者一个人扛。

这是什么

一个专为「老版本」重做的安卓启动器

QCL 的重点不是堆功能，而是解决一个被长期忽略的问题：远古版本（pre-classic / classic / indev / infdev / alpha / beta / RC）到底能不能装、能不能启动。

它是目前手机启动器里唯一支持下载全部考古社区已归档远古版本的（181 个已归档构建； 社区从未归档的构建无法提供下载），也是唯一为「全远古版本」做好中文的启动器。 每个归档构建都会自动补齐依赖与资源文件。

同时它并没有停在过去：版本覆盖一路到最新的 26.x（Java 25）， 版本列表从 26.3 一直排到 a1.2.0_02， 共 114 个正式版。

核心能力

它把功夫花在了哪些地方

这些能力背后，是持续的版本跟进、真机适配与反复调试。

独家

全部已归档远古版本

手机启动器里唯一支持下载考古社区已归档的全部远古版本（181 个构建），并自动补齐依赖与资源。

独家

全远古版本中文

唯一为 pre-classic 到 RC 的所有远古版本做好中文补丁的启动器，老版本也能看懂界面与物品名。

自研

全链路自研

1.1.1 起启动 / 渲染 / 输入 / Java 运行时链路全部自研，以 FCL 为参照实现，不再依赖早期代码核心。

稳定

内存安全夹取

按运行时位数给默认值（64 位 2GB / 32 位 1GB），再按当前剩余内存动态夹取，避免 VM 初始化失败把启动器一起带走。

兼容

32 / 64 位自动检测

跟随设备与应用的实际 ABI 自动选择运行时，也可在设置里手动强制。原生 SDL3 图形窗口，支持 26.3+。

可选

七种渲染器随手切

长按启动键即可切换：Krypton Wrapper / Holy-GL4ES / Zink / VirGL / Freedreno / VGPU / MobileGlues，默认 Krypton，全版本通吃。

可观测

日志悬浮窗与崩溃界面

启动日志悬浮窗默认开启，实时显示 JVM 与游戏输出，进主界面自动关闭；崩溃时有专门的崩溃界面而不是黑屏。

国内优化

镜像加速下载

默认走 BMCLAPI 镜像；Modrinth / CurseForge 通过国内 MCIM 镜像访问，镜像不通自动回退官方。

资源

分页浏览与整合包导入

Mod / 资源包 / 整合包 / 光影 / 世界分页浏览，支持 Prism、MultiMC 整合包导入，导入时自动补下游戏本体。

账号

微软账号与离线账号

启动器内可添加、切换多个微软账号；离线账号默认史蒂夫（宽臂），支持导入 PNG 皮肤，头像与 3D 人物跟随皮肤变化。
